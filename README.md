# 💸 Reward Land

A Telegram Mini App where users complete fun activities, unlock rewards, and enjoy an interactive experience powered by HTML, CSS, and JavaScript.

## Features

* 💸 Earn Rewards While Playing
* 🎁 Daily Bonus
* 📦 Reward Box
* ⭐ Unlock Reward Opportunities
* 📺 Rewarded Ads (Monetag)
* 💾 Local Storage
* 📱 Mobile-Friendly Interface

## Technologies

* HTML5
* CSS3
* JavaScript
* Telegram Mini Apps
* Vercel
* Monetag SDK

## Status

🚀 Active Development

New features, animations, and reward experiences are continuously being improved to provide a smoother and more engaging user experience.
